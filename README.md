# Research Tool

A Windows desktop tool intended to help with research-related work. The repository currently provides the application as a downloadable executable named `Research Tools.exe`.

## Download and run

1. Visit the [repository homepage](https://github.com/FAKE-ARTIST-007/Research-Tool).

1. Download `Research Tools.exe`. Alternatively, choose **Code → Download ZIP** and extract the downloaded archive.

1. On a 64-bit Windows computer, double-click `Research Tools.exe` to launch it.

1. If Windows displays a security warning, verify that the file and its source are expected before running it.

## System and file details

- Operating system: Windows

- Architecture: 64-bit (x86-64)

- Application file: `Research Tools.exe`

- File size: approximately 23 MB
